Vorbis Decoder Cascade Passes per Audio Frame

This article examines the cascade pass architecture defined in the Vorbis I audio specification, detailing the exact number of cascade passes an audio decoder executes per audio frame. During the spectral residue decoding stage, an audio frame reconstructs frequency-domain data using multi-stage vector quantization. The sections below explain the architectural limit of eight cascade passes per residue block, how bitstream headers configure these stages, and how the decoder executes them during frame processing.

The Eight-Pass Architectural Limit

In the Vorbis I specification, a compliant decoder executes a maximum of 8 cascade passes (indexed 0 through 7) per audio frame during the residue decoding stage.

Residue vectors represent the fine spectral details left over after subtracting the spectral floor (Floor 0 or Floor 1) from the audio spectrum. To encode these vectors efficiently, Vorbis uses cascaded (multistage) vector quantization. Instead of quantizing residue values in a single high-resolution step, the encoder quantizes rough approximations in early passes and refines them with residual error values in subsequent passes.

Header Configuration and the 8-Bit Cascade Mask

The number of passes and their active codebooks are configured in the Vorbis setup header during stream initialization:

  1. Classification Setup: The header establishes between 1 and 64 classifications (residue_classifications) to categorize different partitions of the residue spectrum.
  2. Cascade Bitmask: For each classification, the header reads an 8-bit integer acting as a bitmask (often unpacked as a 3-bit low-order value and a 5-bit high-order value).
  3. Pass Mapping: Each bit in this 8-bit mask corresponds directly to one of the 8 potential cascade passes (bits 0 through 7). If bit \(k\) is set, the decoder reads a codebook index for pass \(k\). If bit \(k\) is clear, no codebook is used for that classification during pass \(k\).

Because the cascade allocation is strictly bound to an 8-bit field per classification, the Vorbis format cannot exceed 8 cascade stages.

Execution During Audio Frame Decoding

When an audio frame is decoded, residue formats (Residue 0, Residue 1, or Residue 2) process the spectral data through an outer loop defined strictly by the 8 passes:

  • Loop Execution: The decoder iterates sequentially through pass = 0 to pass = 7.
  • Partition Evaluation: Within each pass, the decoder traverses the audio frame's partitions. It checks the classification assigned to each partition.
  • Vector Accumulation: If the active classification has an assigned codebook for the current pass, the decoder reads symbols from the bitstream, decodes the vector values, and adds them directly to the accumulating residue output buffer.
  • Skipped Passes: If no active classifications utilize a codebook during a particular pass index, the decoder advances without reading bits for that stage.

In summary, while a frame may execute fewer passes if higher-order stages are unused or left empty by the encoder, a Vorbis decoder will never execute more than 8 cascade passes per audio frame.
