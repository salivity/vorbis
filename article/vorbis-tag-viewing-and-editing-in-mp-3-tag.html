Vorbis Tag Viewing and Editing in Mp3tag

Mp3tag provides extensive support for viewing and editing Vorbis comments across audio formats like FLAC, Ogg Vorbis, and Opus. This guide outlines Mp3tag's specific Vorbis metadata features, including multi-field editing, custom comment creation, embedded cover art management, and advanced batch automation.

Supported Vorbis File Formats

Mp3tag natively handles the Vorbis comment metadata standard across various container formats, including:

  • Ogg Vorbis (.ogg)
  • FLAC (.flac)
  • Opus (.opus)
  • Ogg FLAC and Speex (.spx)

Viewing Capabilities

  • File List and Tag Panel Display: Basic Vorbis comments—such as TITLE, ARTIST, ALBUM, TRACKNUMBER, DATE, and GENRE—are instantly visible and customizable within the main file list and the side Tag Panel.
  • Extended Tags Window: Accessible via View > Extended Tags (or Alt + T), this dialog displays the complete list of all Vorbis comment fields stored inside the file, including technical, non-standard, and proprietary vendor tags.
  • Multiple Values per Field: Vorbis comments natively permit repeating the same field name multiple times (such as multiple ARTIST or GENRE tags). Mp3tag visualizes multi-value fields clearly, typically delimiting them with a double backslash (\\).
  • Technical Information: Along with metadata, Mp3tag displays container-level stream properties, such as audio bitrate, sample rate, channels, and duration.

Editing Capabilities

  • Batch Editing: Users can select hundreds of Vorbis-based files simultaneously to apply identical changes to standard tags, track counters, or custom fields in a single operation.
  • Custom Field Creation: Unlike formats with rigid frames, Vorbis comments accept arbitrary field names. Mp3tag allows users to create, modify, or delete any custom key-value pair (such as ORGANIZATION, DISCSUBTITLE, or CATALOGNUMBER) through the Extended Tags dialog.
  • Multi-Value Field Editing: Users can add multiple distinct entries for the same field or split existing single-string values into separate Vorbis comment blocks using actions or the \\ separator.
  • Embedded Artwork Management: Mp3tag supports embedding, extracting, replacing, and removing cover art within FLAC and Ogg containers. It allows setting image types (such as Front Cover, Back Cover, or Artist) and handles standard METADATA_BLOCK_PICTURE structures compliant with Vorbis specifications.

Advanced Metadata Tools

  • Tag to Filename / Filename to Tag: Automatically extract Vorbis tag information from directory and file structures, or rename files based on internal Vorbis metadata using flexible pattern placeholders.
  • Online Database Integration: Automatically query online databases such as Discogs and MusicBrainz to pull accurate metadata and write it directly into Vorbis comment fields.
  • Action Groups (Batch Automation): Create reusable macros to automate repetitive tasks, including case conversion, regular expression replacements, merging multiple fields, and removing unwanted Vorbis tags.
