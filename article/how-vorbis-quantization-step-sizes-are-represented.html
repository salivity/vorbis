How Vorbis Quantization Step Sizes Are Represented

Vorbis audio compression employs an adaptive, psychoacoustically driven quantization scheme rather than a single fixed scalar step size. In Vorbis, spectral coefficients produced by the Modified Discrete Cosine Transform (MDCT) are split into a spectral envelope (the "floor") and residual details (the "residue"). Consequently, quantization step sizes are mathematically represented through a combination of piecewise logarithmic floor functions—which set continuous, frequency-dependent scale factors—and linear vector codebook parameters that define the precision of residual values.

The Quantization Architecture

In the Vorbis specification, spectral reconstruction balances dynamic range against perceptual masking thresholds. The reconstruction of an MDCT spectral coefficient \(X[k]\) at frequency index \(k\) follows the relationship:

\[X[k] = R[k] \times \text{Floor}[k]\]

Where:

  • \(R[k]\) is the dequantized residue value.
  • \(\text{Floor}[k]\) is the spectral envelope synthesized from floor parameters, acting as the local, frequency-dependent quantization step size factor.

Rather than quantizing each MDCT coefficient with an independent step size \(\Delta[k]\), Vorbis normalizes \(X[k]\) by dividing it by the psychoacoustic threshold profile (\(\text{Floor}[k]\)). The resulting unitless quotient \(R[k]\) is then quantized via multidimensional vector codebooks.

Floor 1 Representation (Logarithmic Scale Quantization)

The primary method for encoding the envelope in Vorbis I is Floor 1, which represents the dynamic quantization floor as a piecewise linear curve over a logarithmic frequency axis (Bark-like distribution).

  1. Piecewise Linear Interpolation: Given two anchor points \((X_A, Y_A)\) and \((X_B, Y_B)\) where \(X\) denotes the frequency bin and \(Y\) represents the quantized envelope amplitude, any intermediate point \(X\) is linearly interpolated:

    \[Y = Y_A + \left\lfloor \frac{(Y_B - Y_A) \cdot (X - X_A)}{X_B - X_A} \right\rfloor\]

  2. Log-to-Linear Mapping: The decoded integer \(Y\) corresponds to a step on a logarithmic decibel scale. To convert \(Y\) into a linear multiplier that operates as the dynamic step size, Vorbis uses an exponential lookup table mathematically defined as:

    \[\text{Floor}[k] = \text{FLOOR1\_lookup}[Y[k]] \approx \alpha \cdot \exp\left( \beta \cdot Y[k] \right)\]

    In standard Vorbis implementations, the lookup table models a dynamic range of approximately 140 dB using 8-bit to 12-bit integer values, mapped to floating-point gains ranging from \(0.0\) to \(1.0\).

Codebook Vector Quantization Step Sizes

The residue values \(R[k]\) are reconstructed using vector quantization (VQ) codebooks. Each codebook explicitly stores its internal scalar step size as a floating-point value.

A codebook entry vector \(\vec{V} = [v_0, v_1, \dots, v_{p-1}]\) of length \(p\) is derived from transmitted bitstream indices \(q_0, q_1, \dots, q_{p-1}\) using three parameters defined in the bitstream header:

  • min_value (\(V_{\text{min}}\)): The base offset stored as a 32-bit float.
  • delta_value (\(\Delta_{\text{cb}}\)): The scalar quantization step size, stored as a 32-bit float.
  • sequence_p: A 1-bit sequential flag indicating whether values are absolute or relative deltas.

Non-Sequential Codebook (Absolute)

If sequence_p \(= 0\), the dequantized value of the \(j\)-th dimension is:

\[v_j = q_j \cdot \Delta_{\text{cb}} + V_{\text{min}}\]

Sequential Codebook (Cumulative)

If sequence_p \(= 1\), each element depends on the previous reconstructed value to maintain monotonic energy distributions:

\[v_j = v_{j-1} + q_j \cdot \Delta_{\text{cb}} + V_{\text{min}} \quad (\text{with } v_{-1} = 0)\]

Effective Quantization Step Size

Combining the codebook quantization step \(\Delta_{\text{cb}}\) and the continuous spectral floor \(\text{Floor}[k]\), the effective quantization step size \(\Delta_{\text{eff}}[k]\) applied to any individual MDCT spectral coefficient \(X[k]\) is defined as:

\[\Delta_{\text{eff}}[k] = \Delta_{\text{cb}} \times \text{Floor}[k]\]

This formulation ensures that quantization noise is automatically scaled proportionally to the signal's spectral energy, placing larger quantization intervals in high-energy or masked bands, and finer quantization intervals in perceptually sensitive regions.
