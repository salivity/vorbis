How ogginfo Displays Vorbis Technical Metadata

The command-line utility ogginfo, part of the vorbis-tools suite, inspects Ogg bitstreams and extracts low-level technical parameters and encoding details from multiplexed or standalone media streams. This article explains how ogginfo parses the underlying Ogg container structures, extracts audio stream characteristics from Vorbis-specific headers, and presents operational metrics such as sample rates, bitrate ranges, playback length, and stream integrity verification directly in terminal output.

Ogg Stream Demuxing and Identification

ogginfo operates by reading the Ogg container sequentially from beginning to end. An Ogg file consists of interleaved pages, each designated with a specific serial number to distinguish concurrent logical bitstreams. When ogginfo encounters a new logical bitstream, it reads the initial packet on the first page to identify the codec payload. For a Vorbis audio stream, this packet begins with the signature byte \x01 followed by the ASCII string "vorbis".

Once identified, ogginfo tracks the stream's serial number and prepares to unpack the three mandatory Vorbis header packets required for decoding.

Parsing Vorbis Header Packets

Vorbis metadata is split across three initial packets:

  1. Identification Header: ogginfo reads this first packet to determine the fundamental audio properties. It extracts:

    • Vorbis Version: The version of the Vorbis specification used.
    • Audio Channels: The number of audio channels (e.g., 1 for mono, 2 for stereo, 6 for 5.1 surround).
    • Audio Sample Rate: The sampling frequency expressed in Hertz (Hz).
    • Bitrate Configurations: The encoder's declared maximum, nominal, and minimum bitrates (in bits per second), which indicate whether Variable Bitrate (VBR) or Constant Bitrate (CBR) targeting was requested.
    • Block Sizes: Window block sizes used for audio transform framing.

  2. Comment Header: The second packet contains user-defined metadata and encoder attribution. ogginfo extracts the Vendor String (identifying the specific encoder implementation, such as Xiph.Org libVorbis I 20200704) alongside standard key-value Vorbis comments (e.g., TITLE, ARTIST).

  3. Setup Header: The third header contains codebook and transform configuration data. While mostly internal to the decoder, ogginfo verifies the presence and basic validity of these tables to ensure the stream is decodable.

Stream Traversal and Runtime Calculations

Unlike simple ID3 tag readers that only examine the file's start or end, ogginfo processes all remaining audio pages in the bitstream to calculate runtime metrics:

  • Playback Duration and Total Samples: Vorbis pages store a 64-bit value known as the granulepos (granule position) in their page headers. The granule position represents the exact number of PCM audio samples encoded up to that point. ogginfo records the final granule position of the stream and divides it by the sample rate extracted from the Identification Header, deriving the precise playback duration down to the millisecond.
  • Actual Average Bitrate: ogginfo tallies the total payload bytes belonging to the logical bitstream and divides them by the playback duration. This calculation provides the actual average bitrate, which often differs from the nominal bitrate declared in the header when using Variable Bitrate encoding.
  • Integrity and Sequence Verification: During traversal, ogginfo verifies the continuous increment of page sequence numbers. It checks for truncated packets, corrupted page checksums (CRC32), and premature end-of-stream conditions, warning the user if the stream exhibits integrity issues.

Presentation of Extracted Data

Upon completing the file scan, ogginfo outputs the collected technical data organized per logical bitstream. The resulting output summarizes the technical profile:

Logical stream 12345678 (1) is vorbis
Vorbis headers parsed for stream 12345678, information follows:
Version: 0
Vendor: Xiph.Org libVorbis I 20200704 (Community)
Channels: 2
Rate: 44100

Nominal bitrate: 160.000000 kb/s
Upper bitrate not set
Lower bitrate not set
User comments section follows...
Vorbis stream 1:
    Total data length: 3840234 bytes
    Playback length: 3m:11.453s
    Average bitrate: 160.466842 kb/s
Logical stream 12345678 ended

Through this sequential reading process, ogginfo separates container-level framing from Vorbis codec headers, providing a comprehensive report of both declared configuration settings and observed bitstream behavior.
