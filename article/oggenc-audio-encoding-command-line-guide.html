Oggenc Audio Encoding Command Line Guide

This article provides a practical overview of encoding audio using oggenc, the primary command-line encoder for the Ogg Vorbis audio format. It covers standard command syntax, quality and bitrate controls, audio tagging options, and common operational examples to help you convert uncompressed audio files into compressed Ogg Vorbis streams efficiently.

Basic Command Syntax

The oggenc utility is part of the vorbis-tools package. It reads uncompressed audio formats—primarily WAV, AIFF, or raw PCM—and outputs an .ogg file.

The fundamental command requires only the tool name and the target audio file:

oggenc input.wav

By default, this command encodes input.wav into input.ogg in the same directory using a default quality level of 3 (roughly equivalent to 112 kbps).

To define a custom output file name, use the -o or --output flag:

oggenc input.wav -o custom_name.ogg

Controlling Quality and Bitrates

Ogg Vorbis is inherently a Variable Bitrate (VBR) format. Rather than targeting an exact bitrate, it is best practice to specify a quality level.

Variable Bitrate (Recommended)

The -q or --quality parameter accepts values ranging from -1 (lowest quality, ~45 kbps) to 10 (highest quality, ~500 kbps). Fractional values like 4.5 are also supported.

# High quality encoding (~160 kbps)
oggenc -q 5 input.wav

# Audiophile quality encoding (~320 kbps)
oggenc -q 8 input.wav

Managed Bitrate (ABR/CBR)

If streaming constraints require strict bandwidth limits, you can manage the bitrate directly using -b (nominal bitrate), -m (minimum bitrate), and -M (maximum bitrate) specified in kilobits per second (kbps):

# Target an average bitrate of 128 kbps
oggenc -b 128 input.wav

# Constrain between 96 kbps and 192 kbps with a 128 kbps target
oggenc -m 96 -b 128 -M 192 input.wav

Adding Vorbis Comment Metadata

oggenc allows you to write metadata tags directly during the encoding process.

  • -t, --title: Track title
  • -a, --artist: Artist name
  • -l, --album: Album title
  • -d, --date: Release date/year
  • -N, --tracknum: Track number
  • -G, --genre: Genre
  • -c, --comment: Custom tag in FIELD=VALUE format

Example:

oggenc track01.wav \
  -a "Artist Name" \
  -l "Album Name" \
  -t "Song Title" \
  -d "2024" \
  -N "1" \
  -G "Electronic" \
  -c "DISCNUMBER=1"

Processing and Audio Adjustments

You can apply basic audio transformations during the encoding step:

  • Downmixing to Mono: Use --downmix to convert stereo audio into a single channel. 
    oggenc --downmix stereo_input.wav -o mono_output.ogg
  • Resampling: Use --resample <rate> to change the sample rate (e.g., to 44100 Hz). 
    oggenc --resample 44100 48khz_audio.wav

Batch Processing

To encode multiple files at once, pass wildcards or a list of files:

oggenc -q 6 *.wav

To encode files and output them to a specific target directory, use the -d flag:

oggenc -q 6 *.wav -d /path/to/destination/
