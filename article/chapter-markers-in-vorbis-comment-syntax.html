Chapter Markers in Vorbis Comment Syntax

Vorbis comments provide a simple, text-based metadata system commonly used in audio formats like Ogg Vorbis, FLAC, and Opus. While Vorbis comments do not have a dedicated binary chapter structure like MP4 or ID3v2, they support chapter markers through a standardized naming convention adapted from Matroska's basic chapter system. This guide explains the required syntax, timestamp formats, and naming rules needed to implement chapter markers properly.

The Basic Structure

Chapter markers in Vorbis comments rely on paired key-value fields sharing a sequential identifier. For every chapter, you must define at least two fields: the start time and the chapter title.

The standard naming scheme follows this format:

CHAPTERxxx=hh:mm:ss.sss
CHAPTERxxxNAME=Chapter Title
  • CHAPTERxxx: Specifies the start time of the chapter.
  • CHAPTERxxxNAME: Specifies the display name or label for that chapter.
  • xxx: A zero-padded, sequential numerical index (e.g., 001, 002, 003).

Timestamp Formatting

Timestamps must strictly adhere to the hh:mm:ss.sss format:

  • Hours (hh): Two digits representing the hour (e.g., 00 or 01).
  • Minutes (mm): Two digits from 00 to 59.
  • Seconds (ss): Two digits from 00 to 59.
  • Milliseconds (sss): Three digits representing fractions of a second separated by a period (not a comma).

A chapter does not require an explicit end-time field; a player determines a chapter's end by the start timestamp of the subsequent chapter or the end of the media file.

Example Implementation

A standard three-chapter file is written as follows:

CHAPTER001=00:00:00.000
CHAPTER001NAME=Introduction
CHAPTER002=00:03:45.500
CHAPTER002NAME=The Main Interview
CHAPTER003=00:18:22.125
CHAPTER003NAME=Outro and Credits

Optional Chapter Attributes

In addition to timestamps and names, the Vorbis comment chapter specification allows optional metadata per chapter:

  • CHAPTERxxxURL: Attaches a web link relevant to that specific chapter section.
  • CHAPTERxxxLANG: Defines the language of the chapter name using standard ISO language codes (e.g., en, de).
CHAPTER001=00:00:00.000
CHAPTER001NAME=Introduction
CHAPTER001URL=https://example.com/episode-notes

Best Practices

  • Always zero-pad indices: Use three digits (001 through 999) to preserve chronological sorting in simple text parsers.
  • Sequential order: Keep chapters numbered sequentially without skipping numbers.
  • UTF-8 encoding: Like all Vorbis comment values, chapter names must be encoded in UTF-8 to support international characters and special symbols.
