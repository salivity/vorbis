Can Vorbis Encode Frequencies Above 20 kHz?

Ogg Vorbis can technically encode ultrasonic frequencies above 20 kHz, but it depends heavily on the input sample rate and encoder configuration. Because Vorbis is a lossy psychoacoustic audio format, its default settings intentionally filter out frequencies above the threshold of human hearing to conserve bandwidth. However, by using high-resolution audio sources and disabling or adjusting the lowpass filter in the encoder, ultrasonic frequencies can be retained.

Sample Rate Requirements

To preserve frequencies above 20 kHz, the input audio must have a sampling rate higher than the standard 44.1 kHz. According to the Nyquist-Shannon sampling theorem, an audio file can only represent frequencies up to half of its sampling rate:

  • A 44.1 kHz file has a theoretical limit of 22.05 kHz.
  • A 48 kHz file can encode frequencies up to 24 kHz.
  • A 96 kHz file can encode frequencies up to 48 kHz.

The Vorbis bitstream specification natively supports arbitrary sample rates up to \(2^{32}-1\) Hz, meaning the format itself imposes no rigid ceiling that would restrict high-resolution or ultrasonic content.

Psychoacoustic Lowpass Filtering

Standard implementations, such as the reference libvorbis encoder (oggenc), rely on psychoacoustic tuning to optimize file size and perceptual quality. Human hearing typically caps out around 20 kHz (and often lower in adults). Consequently, Vorbis encoders routinely apply an automatic lowpass filter at low-to-medium bitrates, stripping away audio above 16 kHz to 20 kHz to allocate available bits to audible ranges.

If you encode a 96 kHz file using standard quality presets (such as -q 4 or -q 6), the encoder will usually cut off ultrasonic information regardless of the source file's bandwidth.

Preserving Ultrasonic Frequencies

To capture ultrasonic signals above 20 kHz with Vorbis:

  1. Use High-Quality Presets: Setting the quality level to maximum (-q 10 in oggenc) pushes the lowpass filter threshold higher, preserving more top-end extension.
  2. Disable the Lowpass Filter: Using command-line switches such as --ignore-length or explicit frequency flags (e.g., --lowpass-frequency set higher than 20000, depending on the frontend build) allows users to bypass aggressive psychoacoustic culling.

While Vorbis can store these frequencies, lossy compression often introduces artifacts or struggles with efficiency when forced to preserve non-audible data. For purely ultrasonic applications—such as bioacoustics, bat echolocation recording, or scientific data collection—lossless formats like FLAC are standard, though Vorbis remains technically capable of the task when configured properly.
