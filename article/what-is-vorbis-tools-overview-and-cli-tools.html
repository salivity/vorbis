What Is vorbis-tools: Overview and CLI Tools

vorbis-tools is a standard collection of command-line utilities designed for creating, playing, inspecting, and editing Ogg Vorbis audio streams. Maintained under the umbrella of the Xiph.Org Foundation, this package provides the core terminal-based toolset for interacting with the open-source Vorbis audio format. This article covers what the package does and details the core tools it provides: oggenc, oggdec, ogg123, ogginfo, vorbiscomment, and vcut.

What Is vorbis-tools?

vorbis-tools is the official set of reference utilities for the Ogg Vorbis audio compression format. Ogg Vorbis is a patent-free, high-quality, lossy audio codec developed as an alternative to proprietary formats like MP3 and AAC. While modern operating systems and media players contain built-in decoders, vorbis-tools provides system administrators, developers, and command-line users with direct, lightweight access to encode, decode, diagnose, and tag these files.

Core Command-Line Utilities in vorbis-tools

The package includes six distinct utilities, each specialized for a specific audio-handling task.

1. oggenc (Audio Encoder)

oggenc encodes raw, WAV, AIFF, or FLAC audio files into the Ogg Vorbis format (.ogg). It offers extensive options for controlling variable bitrate (VBR) quality settings, downmixing channels, and adding metadata during the encoding process.

  • Primary Use: Converting uncompressed audio to compressed Ogg files.
  • Basic Example: 
    oggenc -q 6 input.wav -o output.ogg
    (The -q flag specifies a quality level from -1 to 10, with 6 providing roughly 192 kbps nominal bitrate.)

2. oggdec (Audio Decoder)

oggdec handles the inverse operation of oggenc. It takes an Ogg Vorbis file and decompresses it back into an uncompressed format, typically a standard PCM WAV file or raw audio stream.

  • Primary Use: Decompressing Ogg Vorbis tracks for editing, CD burning, or compatibility with tools that require raw audio.
  • Basic Example: 
    oggdec input.ogg -o output.wav

3. ogg123 (Audio Player)

ogg123 is a fast, terminal-based audio player. It can play Ogg Vorbis, FLAC, and Ogg Speex streams through various audio output systems, including ALSA, PulseAudio, OSS, or directly to standard output. It supports network streams via HTTP URLs as well as local playlists.

  • Primary Use: Playing audio tracks directly from the shell without launching a graphical user interface.
  • Basic Example: 
    ogg123 track.ogg

4. ogginfo (Stream Analyzer and Diagnostics)

ogginfo inspects an Ogg stream at the bitstream level. It validates file integrity, detects stream corruptions, and prints detailed technical metadata, including sampling rate, channel count, nominal bitrate, playback length, and embedded comment headers.

  • Primary Use: Troubleshooting broken files, verifying audio properties, and confirming encoding parameters.
  • Basic Example: 
    ogginfo track.ogg

5. vorbiscomment (Metadata Editor)

vorbiscomment reads, edits, and writes metadata tags (Vorbis comments) within an existing Ogg Vorbis file without requiring the audio data to be re-encoded. Tags are stored as plain key-value pairs (e.g., TITLE=Song Name, ARTIST=Artist Name).

  • Primary Use: Batch tagging, automated script-based tag updates, and viewing embedded metadata.
  • Basic Example (Listing Tags): 
    vorbiscomment -l track.ogg
  • Basic Example (Writing Tags): 
    vorbiscomment -a -t "ARTIST=Example Artist" track.ogg

6. vcut (File Splitter)

vcut is designed to split a single Ogg Vorbis file into two separate files at a specific cutpoint. Cutpoints can be specified by time offset or sample position. Because it works directly on packet boundaries, it splits files without decompressing or re-encoding the audio stream.

  • Primary Use: Splitting large audio recordings (such as podcasts or live sets) into smaller segments.
  • Basic Example: 
    vcut input.ogg output_part1.ogg output_part2.ogg +01:30.00
