ReplayGain Specification for Vorbis Audio Files

The ReplayGain specification for Vorbis audio files outlines how players and encoders store and interpret loudness normalization metadata within Ogg Vorbis streams. Unlike formats that rely on specialized binary headers or ID3 tags, Vorbis implements ReplayGain using standard Vorbis comment fields. This approach allows compatible media players to automatically adjust playback volume to achieve a consistent perceived loudness across different tracks and albums without altering the underlying audio data.

How ReplayGain Works in Vorbis

ReplayGain operates non-destructively by analyzing the perceived loudness of an audio file using an algorithm based on human hearing curves. The resulting calculation is stored as metadata. When a file is decoded, the player reads these values and applies a gain adjustment during playback. If a player does not support ReplayGain, it simply ignores the tags and plays the file at its standard encoded volume.

Standard Vorbis Comment Fields

In Vorbis audio files, ReplayGain metadata is stored within standard, human-readable UTF-8 Vorbis comment tags (field-name=value format). The specification defines four primary fields, split between track-level and album-level calculations:

  • REPLAYGAIN_TRACK_GAIN: A floating-point number representing the gain adjustment required to bring the individual track to the standard target loudness level (typically 89 dB SPL). The value is signed and explicitly followed by the unit dB (e.g., -4.52 dB or +1.20 dB).
  • REPLAYGAIN_TRACK_PEAK: A floating-point number representing the peak signal level of the individual track, expressed as a ratio where 1.0 corresponds to digital full-scale (0 dBFS). For example, a value might be 0.985421.
  • REPLAYGAIN_ALBUM_GAIN: A signed floating-point number specifying the gain adjustment required to normalize the entire album while preserving the intentional relative volume differences between tracks. Like track gain, it includes the dB suffix (e.g., -3.10 dB).
  • REPLAYGAIN_ALBUM_PEAK: A floating-point ratio representing the maximum peak signal across the entire album relative to full-scale (1.0).

An optional fifth field, REPLAYGAIN_REFERENCE_LOUDNESS, is sometimes included to denote the reference level used during the initial calculation (for example, 89.0 dB), though modern implementations generally rely on the 89 dB SPL standard by default.

Formatting Rules

Vorbis field names are case-insensitive according to the Vorbis comment specification, but ReplayGain implementations conventionally write them in uppercase. Gain values must always include the sign (+ or -), at least one decimal place, and the dB unit suffix to ensure maximum compatibility across various decoders. Peak values should be written with standard decimal notation rather than exponential notation.
