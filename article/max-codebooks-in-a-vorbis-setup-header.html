Max Codebooks in a Vorbis Setup Header

This article explains the technical limitations governing codebook definitions within the Vorbis audio codec specification. It specifically examines the Vorbis setup header, detailing how codebook counts are serialized in bitstreams, the maximum number of codebooks that can be declared in a single stream, and how decoders interpret these fields.

According to the official Vorbis I specification, the maximum number of codebooks a single Vorbis setup header can declare is 256.

When a Vorbis decoder processes the setup header to configure stream parameters, it reads the codebook configuration during the initial header decode phase:

  1. The decoder reads an 8-bit unsigned integer from the bitstream.
  2. It increments this 8-bit value by 1 to determine [vorbis_codebook_count].

Because an 8-bit unsigned integer holds values ranging from 0 to 255 (binary 00000000 to 11111111), adding 1 produces a valid range of 1 to 256. Consequently, a Vorbis setup header must declare at least 1 codebook and can declare no more than 256 codebooks. This design guarantees that every valid Vorbis stream includes the minimum required quantization and entropy decoding information while capping header memory consumption during decoding initialization.
