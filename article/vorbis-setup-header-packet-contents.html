Vorbis Setup Header Packet Contents

The Vorbis setup header is the third and most complex header packet required to initialize an Ogg Vorbis decoder. It provides the complete structural and mathematical configuration needed to reconstruct compressed audio, defining the vector quantization codebooks, spectral envelope representations, residue decoders, channel mappings, and operational modes. Without this packet, the raw audio packets in the stream cannot be interpreted.

Codebooks

The setup header contains an array of static codebooks used for vector quantization and Huffman-style entropy decoding. Each codebook definition includes:

  • Codebook Dimensions: The number of scalar values represented by a single codebook entry.
  • Codebook Entries: The total number of unique symbols or codewords.
  • Codeword Lengths: The bit lengths for each codeword, defining the prefix tree.
  • Lookup Tables: Value tables used for vector decoding (either unpopulated, uniformly spaced, or explicitly enumerated coordinate lists).

Time-Domain Transforms

Vorbis reserves fields for time-domain transform configurations. While specified in the packet format to maintain forward compatibility, modern Vorbis (Vorbis I) implementations bypass these structures, setting their count to zero or reserving them without active functional parameters.

Floors

Floors describe the low-resolution spectral envelope of the audio signal. The setup header configures the specific floor types and their decoding parameters:

  • Floor 0: A linear predictive coding (LPC) and line spectral pair (LSP) based model, specifying order, bark map sizes, and codebook associations.
  • Floor 1: A piecewise linear curve representation, detailing the number of X-axis partition points, partition classes, class dimensions, and associated codebooks for interpolating the frequency curve.

Residues

Residues represent the fine-detail spectral data remaining after subtracting the spectral floor. The setup header defines the residue types (Residue 0, 1, or 2) and their execution parameters:

  • Frequency boundary limits (starting and ending spectral offsets).
  • Partition sizes and classifications.
  • Specific codebook assignments mapped to each partition and stage of the residue pass.

Mappings

Mappings configure how multiple audio channels relate to each other, defining channel coupling and linking floors to residues:

  • Channel Coupling: Submap rules detailing angle and magnitude relationships between channels to enable stereo or surround coupling.
  • Floor and Residue Binding: Assignments designating which floor and residue configurations apply to each channel or coupled channel pair.

Modes

The final section of the setup header lists the mode definitions. Every audio packet begins with a short mode index, which references one of these modes:

  • Block Flag: Specifies whether the packet utilizes a short window (for transients) or a long window (for high spectral resolution).
  • Mapping Association: Points directly to the specific mapping configuration required to decode the packet.
