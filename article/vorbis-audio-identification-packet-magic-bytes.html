Vorbis Audio Identification Packet Magic Bytes

This article explains the magic byte sequence used to identify a Vorbis audio identification packet within an audio stream. It breaks down the exact hexadecimal and ASCII representations of the sequence, details the structure of the packet header, and outlines the role this sequence plays in decoding Ogg Vorbis media.

The Magic Byte Sequence

The magic byte sequence that identifies a Vorbis audio identification packet is a 7-byte sequence:

  • Hexadecimal: 0x01 0x76 0x6F 0x72 0x62 0x69 0x73
  • ASCII / String representation: \x01vorbis

Any parser reading a Vorbis bitstream expects this exact sequence at the start of the primary identification packet.

Byte Breakdown

The 7-byte identifier consists of two distinct components:

  1. Packet Type Flag (0x01): The first byte indicates the header packet type. Vorbis defines three specific header packet types that must appear in order at the start of an audio stream:
    • 0x01: Identification packet
    • 0x03: Comment packet
    • 0x05: Setup (codebook) packet
  2. Identifier String (vorbis): The remaining six bytes are the ASCII representation of the lowercase string "vorbis" (0x76, 0x6F, 0x72, 0x62, 0x69, 0x73).

Role in Stream Parsing

In an Ogg container, the identification packet is the very first packet of a Vorbis logical bitstream. Demuxers and decoders read the initial 7 bytes to confirm that the encapsulated stream is indeed Vorbis audio rather than another codec such as Theora, FLAC, or Opus.

Immediately following the \x01vorbis sequence, the packet provides fundamental stream parameters:

  • Vorbis Version: 4 bytes (32-bit unsigned integer, typically 0x00000000)
  • Audio Channels: 1 byte (unsigned 8-bit integer representing channel count)
  • Audio Sample Rate: 4 bytes (32-bit unsigned integer, in Hz)
  • Bitrate Maximum: 4 bytes (32-bit signed integer)
  • Bitrate Nominal: 4 bytes (32-bit signed integer)
  • Bitrate Minimum: 4 bytes (32-bit signed integer)
  • Block Sizes: 1 byte (encodes two block sizes as powers of two)
  • Framing Bit: 1 bit (must be set to non-zero 1 to validate the packet)

If the first 7 bytes do not match 0x01 0x76 0x6F 0x72 0x62 0x69 0x73, the decoder rejects the stream as an invalid or corrupted Vorbis bitstream.
