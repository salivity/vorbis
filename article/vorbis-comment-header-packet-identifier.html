Vorbis Comment Header Packet Identifier

This article provides an overview of the technical structure of Ogg Vorbis headers, specifically focusing on the exact sequence of bytes used to identify metadata packets. It details how the Vorbis comment header packet is recognized within a bitstream, how its identifier is composed, and how it compares to other standard header types in the Vorbis audio specification.

The Identification Sequence

The Vorbis comment header packet is identified by the 7-byte sequence \x03vorbis.

In hexadecimal notation, the bytes are represented as: 0x03 0x76 0x6F 0x72 0x62 0x69 0x73

Packet Structure Breakdown

  1. Packet Type Byte (0x03): The initial byte designates the packet as a comment (metadata) header. In the Vorbis specification, all header packets begin with an explicit 1-byte integer indicating their purpose.
  2. Identifier String ("vorbis"): The subsequent 6 bytes consist of the continuous, lowercase ASCII string "vorbis". This confirms that the stream belongs to the Vorbis codec family and guards against bitstream desynchronization.

Comparison to Other Vorbis Headers

A standard Ogg Vorbis stream requires three sequential header packets to initialize decoding. Each header shares the "vorbis" string but is differentiated by its leading packet type byte:

  • Identification Header: \x01vorbis (0x01 + "vorbis") — Contains basic stream parameters like sample rate, channels, and block sizes.
  • Comment Header: \x03vorbis (0x03 + "vorbis") — Contains user-readable metadata, including vendor tags, artist names, and track titles.
  • Setup Header: \x05vorbis (0x05 + "vorbis") — Contains codebooks and floor/residue setup modes necessary to decode audio data.

Function in Stream Decoding

When an Ogg demuxer or Vorbis parser encounters a packet beginning with \x03vorbis, it identifies the packet as the comment structure. Immediately following these 7 bytes, the parser expects a 32-bit little-endian integer defining the vendor string length, followed by the vendor string and the user-defined Vorbis comment fields.
