Maximum File Size of an Ogg Vorbis Stream

This article examines the maximum file size limits of an Ogg Vorbis bitstream by analyzing the underlying specifications of the Ogg container format and the Vorbis audio codec. While the theoretical limit of a single continuous Ogg logical bitstream reaches approximately 281.47 terabytes, stream chaining features allow it to be virtually infinite. In practice, file system limits and player implementation constraints determine the real-world threshold.

The Ogg Container Specifications

Vorbis is an audio coding format, but file sizes and streaming constraints are governed by its container format, Ogg. The Ogg transport bitstream is organized into sequential packets grouped into "pages." Each page carries specific metadata that determines the size boundaries:

  • Page Size: An Ogg page contains an array of up to 255 segments, with each segment holding a maximum of 255 bytes. This limits the maximum payload of a single Ogg page to 65,025 bytes (roughly 64 KB), excluding the header.
  • Page Sequence Number: Each page within a logical bitstream includes a 32-bit unsigned integer representing the sequence number. This allows up to 4,294,967,296 (\(2^{32}\)) pages in a single sequence.

Multiplying the maximum payload size (65,025 bytes) by the maximum number of sequence pages (\(2^{32}\)) results in a theoretical maximum of roughly 281.47 terabytes (TB) for a single logical bitstream.

Audio Duration Limits (Granule Position)

The Ogg Vorbis specification uses a 64-bit signed integer for the "granule position," which tracks the exact audio sample count for decoding and seeking. Even at extremely high sampling rates, such as 192 kHz, a 64-bit sample counter allows for over 1.5 million years of continuous audio playback before numeric overflow occurs, ensuring that playback duration does not limit file size.

Chained Streams and Unbounded Limits

Ogg natively supports chained streams, meaning multiple logical bitstreams can be appended end-to-end within the same physical file or stream. When a logical bitstream finishes, a new bitstream can begin with its page sequence counter reset to zero. Because of this architecture, the Ogg specification has no inherent cap, allowing continuous or live bitstreams to run infinitely without terminating.

Real-World Constraints

Although the specification accommodates hundreds of terabytes or unbounded streams, actual limits depend on external factors:

  1. File Systems: Storing an Ogg Vorbis file locally is bounded by the storage volume's file system (for example, 4 GB on FAT32 or 16 TB on standard ext4 setups).
  2. Software Implementations: Many audio players and decoders use 32-bit signed file-offset pointers, which can cause playback errors or prevent seeking in files that exceed 2 gigabytes (GB) or 4 gigabytes (GB).
