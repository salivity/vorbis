Transfer Vorbis Comments To and From FLAC Losslessly

FLAC natively utilizes the Vorbis comment specification to store metadata, meaning all tags exist as UTF-8 encoded text pairs rather than binary audio frames. Because both formats share the exact same tagging standard, transferring Vorbis comments between text files, Ogg Vorbis streams, and FLAC containers is inherently lossless. This guide explains how to extract, import, and directly pipe Vorbis comments to and from FLAC files using standard command-line tools without altering the underlying audio streams.

The Underlying Mechanism

Vorbis comments are structured as simple FIELD=Value strings inside a dedicated FLAC metadata block (METADATA_BLOCK_VORBIS_COMMENT). Transferring these tags does not touch the audio blocks, preventing any generation loss or re-encoding. To perform these operations losslessly, official utilities like metaflac (from the FLAC project) and vorbiscomment (from vorbis-tools) are the standard implementations.

Extracting Vorbis Comments from a FLAC File

To export Vorbis comments from a FLAC file into a plain-text file, use the official metaflac command-line utility.

Run the following command:

metaflac --export-tags-to=metadata.txt input.flac

This writes all metadata key-value pairs (such as ARTIST=, ALBUM=, and TITLE=) directly to metadata.txt while preserving UTF-8 character encoding.

Importing Vorbis Comments into a FLAC File

When importing metadata from a text file back into a FLAC container, it is best practice to first clear existing tags to prevent duplicate or conflicting fields.

To overwrite existing tags and apply the new ones losslessly:

metaflac --remove-all-tags --import-tags-from=metadata.txt target.flac

If you only want to append tags without removing existing ones, omit the --remove-all-tags flag:

metaflac --import-tags-from=metadata.txt target.flac

Direct Transfer Between Ogg Vorbis and FLAC

You can transfer metadata directly between an Ogg Vorbis file (.ogg) and a FLAC file (.flac) without generating intermediate text files by piping standard output.

From Ogg Vorbis to FLAC:

vorbiscomment -l source.ogg | metaflac --remove-all-tags --import-tags-from=- destination.flac

From FLAC to Ogg Vorbis:

metaflac --export-tags-to=- source.flac | vorbiscomment -w -c - destination.ogg

In both instances, the - argument denotes standard input/output, ensuring the exact tag payload transfers in-memory without modification.

Transferring Between Two FLAC Files

To mirror tags losslessly from one FLAC file to another:

metaflac --export-tags-to=- source.flac | metaflac --remove-all-tags --import-tags-from=- destination.flac

Key Considerations for Lossless Integrity

  • Character Encoding: Always ensure external text editors or shell environments preserve strict UTF-8 formatting. Non-UTF-8 characters violate the Vorbis specification and will cause parsing errors.
  • Avoid ID3 Tags: Never use tools that inject ID3v2 tags into FLAC files. While some media players tolerate ID3 headers on FLAC containers, they violate the FLAC specification and can cause native Vorbis comments to be ignored or corrupted.
  • Embedded Artwork: Vorbis comments strictly hold text metadata. Embedded album art is stored in a separate FLAC metadata block (METADATA_BLOCK_PICTURE). To transfer cover art losslessly, use metaflac --export-picture-to= and metaflac --import-picture-from= separately.
