Vorbis Residue Partition Sizes in Quantization

This article explains how the Vorbis audio codec handles residue partition sizes during its quantization and entropy-encoding stages. It examines how spectral residue vectors are divided into fixed-width sub-vectors, how these partitions are mapped to statistical classes, and how the multi-pass vector quantization pipeline applies codebooks to balance bit allocation and psychoacoustic fidelity.

The Role of Residue in Vorbis Encoding

In the Vorbis pipeline, time-domain audio samples are converted into the frequency domain via the Modified Discrete Cosine Transform (MDCT). The resulting spectrum is decomposed into two distinct components: the "floor," which represents the broad spectral envelope, and the "residue," which consists of the fine spectral detail remaining after the floor curve is subtracted. Quantizing this residue represents the bulk of the final bitstream's data footprint.

Defining Residue Partitions

To quantize the residue spectrum efficiently, Vorbis divides the range of spectral coefficients into discrete, equal-length segments known as partitions.

  1. Boundary Specification: A Vorbis residue configuration defines an active spectral band delimited by residue_begin and residue_end. Any coefficients outside this range are treated as zero and ignored.
  2. Fixed Partition Sizes: The active range is subdivided into blocks defined by the parameter residue_partition_size. This value is predetermined and encoded within the bitstream setup header. Every partition within a given residue configuration contains the exact same number of spectral values.
  3. Alignment: The total number of encoded coefficients must be an exact multiple of the partition size. If the distance between residue_begin and residue_end does not align perfectly with the partition size, the operational range is padded or truncated to ensure all partitions remain uniform.

Classification and Codebook Association

Residue quantization does not process each partition with an independent, arbitrary codebook. Instead, Vorbis employs a classification scheme to group partitions of similar energy levels together:

  • The Classification Pass: Vorbis groups a predetermined number of adjacent partitions together. An entry from a classification codebook is selected to assign a specific "class" integer to each partition in the group. This single classification word dictates the coding strategy for multiple partitions at once, reducing bit overhead.
  • Classbooks: The assigned class determines which vector quantization (VQ) codebooks will be applied to that partition across subsequent encoding passes. Partitions with negligible energy can be assigned to a zero class, requiring no further bits, while high-energy partitions are mapped to classes that allow for finer quantization.

Vector Quantization and Multi-Pass Cascades

Once partition boundaries and classes are established, the coefficients within each partition are quantized in stages using cascaded Vector Quantization:

  • Dimension Divisibility: A partition consists of scalar frequency values, but Vorbis quantizes data in small vectors (typically of dimension 2, 4, or 8). The residue_partition_size must be an integer multiple of the vector dimensions defined in the active codebooks. A partition is thus treated as an array of smaller vectors encoded sequentially.
  • Cascade Passes: Quantization occurs over multiple passes (stages). In the first pass, a coarse codebook quantizes the broad amplitude of the vectors in a partition. In subsequent passes, additional codebooks quantize the residual error left by the preceding pass. Partitions designated with higher classes participate in more cascade passes, receiving higher bit allocation.

Residue Types and Channel Handling

Vorbis supports three residue formats (Residue 0, Residue 1, and Residue 2), which handle partition layout across audio channels differently:

  • Residue 0: Encodes spectral values sequentially, interleaving dimensions across channels within the partition.
  • Residue 1: Encodes each audio channel independently. Each channel has its own set of partitions spanning from residue_begin to residue_end.
  • Residue 2: Interleaves channel data across the frequency domain before partitioning. Partition boundaries are calculated over a unified, interleaved residue vector. In a stereo configuration with a partition size of 32, for example, each partition contains 16 coefficients from the left channel interleaved with 16 coefficients from the right channel.

By utilizing uniform partition sizes linked to multi-pass classification tables, Vorbis adapts its vector quantization locally to localized spectral energy variations while keeping the framing overhead minimal.
