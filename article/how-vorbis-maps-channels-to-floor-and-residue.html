How Vorbis Maps Channels to Floor and Residue

In the Vorbis audio codec, the synthesis of spectral data relies on dividing the spectral envelope into a coarse "floor" and a fine detailed "residue." The association between input audio channels and their corresponding floor and residue sub-blocks is orchestrated entirely by Vorbis Mapping Type 0. This mapping mechanism organizes channels into discrete submaps, configures channel-coupling steps (such as mid/side or polar stereo), and assigns explicit index references that route each physical or coupled audio channel to the appropriate floor and residue decoding engines.

The Role of Mapping Type 0

Vorbis bitstreams define decoding parameters through configuration headers. Within these headers, the "Mapping" component acts as the central router between raw channel data and the DSP decoding sub-blocks.

A single Vorbis stream can contain multiple mapping configurations, dynamically selected per audio frame (packet) depending on block size (short or long windows). When an audio frame is decoded, the header indicates which mapping applies. Mapping Type 0 then dictates:

  1. The assignment of audio channels to submaps.
  2. The channel coupling relationships (angle/magnitude transformation).
  3. The specific floor sub-block instance assigned to each channel.
  4. The specific residue sub-block instance assigned to each submap.

Mapping Channels to Floor Sub-blocks

The floor represents the overall spectral curve (formant structure) of an audio channel. In Vorbis, floor decoding occurs independently on a per-channel basis:

  • Direct Channel-to-Floor Association: Inside Mapping Type 0, the bitstream provides a list of floor configuration indices corresponding to each channel. If an audio stream contains \(N\) channels, the mapping contains an array of \(N\) floor configuration pointers.
  • Submap Routing: Mapping Type 0 can divide channels into multiple submaps. Each submap references a specific floor configuration. The mapping structure dictates which submap an individual channel belongs to, effectively binding that channel to the floor type assigned to that submap.
  • Execution: During packet decode, the decoder reads and decodes floor parameters for each channel independently using that channel's designated floor engine (typically Floor 1, which uses a piecewise linear representation based on Bark scale frequencies).

Channel Coupling (Polar Mapping)

Before residue vectors are mapped and decoded, Vorbis allows channels to be coupled to exploit inter-channel correlation. Mapping Type 0 specifies an arbitrary number of coupling steps:

  • Each coupling step defines a magnitude channel and an angle channel.
  • This enables transformations like standard Left/Right to Mid/Side stereo, as well as complex phase/point-stereo coupling.
  • The coupling definition specifies which physical channel indices are paired together before residue decoding takes place.

Mapping Channels to Residue Sub-blocks

The residue represents the fine spectral detail remaining after the floor envelope is subtracted from the original spectral signal. While floors are evaluated per-channel, residues can be decoded across multiple channels simultaneously:

  • Submap Assignment: Mapping Type 0 groups channels into submaps. Each submap is assigned exactly one residue sub-block index.
  • Residue Block Association: All channels (or coupled channel pairs) grouped under a given submap share that submap's designated residue decoder (Residue 0, 1, or 2).
  • Interleaved vs. Independent Decoding:
    • In Residue Type 1, spectral vectors for the assigned channels are decoded independently.
    • In Residue Type 2, all channels assigned to the submap are interleaved into a single continuous vector and decoded jointly via the residue's vector quantization codebooks. This is common in stereo configurations where coupling has grouped left and right channels into angle and magnitude channels.

The Complete Channel Routing Flow

When an audio packet is processed, Vorbis resolves channel-to-sub-block mapping through the following sequential pipeline:

  1. Header Lookup: The frame identifies which Mapping Type 0 instance governs the current block.
  2. Floor Decoding: For each channel, the decoder looks up the channel's floor assignment via the mapping's submap configuration, reading the floor data to establish the spectral envelope.
  3. Residue Decoding: For each submap, the decoder executes the assigned residue engine to reconstruct the residue coefficients for all channels associated with that submap.
  4. Decoupling: If coupling steps are defined in the mapping, the decoder performs angle/magnitude inverse transformation to convert the coupled residue data back into standard multi-channel representation.
  5. Synthesis: For each channel, the individual residue vector is multiplied by (or added to, depending on the floor representation) the channel's corresponding floor curve, reconstructing the full MDCT spectrum for that audio channel.
